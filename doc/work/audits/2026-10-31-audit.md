close, and leaves its `implement` stage unchanged. It does not implement the
new features.

  suite checks exact threshold boundaries, remainder ties and tie order, seat
  sums, seeded cases, repeated results, JSON round trips and locale
  independence. Existing static tests scan engine source for floating-point
  and locale-sensitive tokens; a targeted UI scan found no second seat
  calculation or floating-point decision implementation.
- `npm test` passed: **40 files, 2,511 tests**. The previously audited 3.25%
  questionnaire threshold regression is covered, but green tests do not cover
